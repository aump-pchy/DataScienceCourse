เปิดคาบ: ลูปแข่งกับ NumPy

cell แรก นับคนสอบผ่านจากข้อมูล 10 คนเหมือน S0 ข้อ 2 แล้วเทียบกับวิธี NumPy

import numpy as np

scores_list = [72, 85, 64, 91, 58, 77, 88, 49, 95, 70]

# แบบ S0: ใช้ลูป
passed = 0
for s in scores_list:
    if s >= 50:
        passed += 1
print("แบบลูป:", passed)

# แบบ NumPy: บรรทัดเดียว
scores = np.array(scores_list)
print("แบบ NumPy:", (scores >= 50).sum())

ทีนี้ลองข้อมูล 1,000,000 คน แยกเป็น 3 cell แล้วดูเวลาที่ Colab แสดงใต้ cell (%%time ต้องอยู่บรรทัดแรกของ cell)

big = np.random.randint(0, 101, 1_000_000)   # สุ่มคะแนน 0-100 จำนวน 1 ล้านคน
big_list = big.tolist()
%%time
passed = 0
for s in big_list:
    if s >= 50:
        passed += 1
print(passed)
%%time
print((big >= 50).sum())
ดูช่อง Wall time ของสอง cell แล้วจดลง Text cell ว่า NumPy เร็วกว่ากี่เท่า ตัวเลขของแต่ละคนจะไม่เท่ากันก็ไม่เป็นไร

Level 5 Boss: รายงานร้านในฟังก์ชันเดียว
