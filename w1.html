Python Warm-up: ร้านชาไทยหน้าโรงเรียน

ร้านชาไทยแก้วละ 25 บาทจะเป็นโจทย์ของเราทั้งหน้า เราจะคิดรายได้ เช็คเป้ายอดขาย รวมยอดหลายวัน และสร้างฟังก์ชันไว้ใช้ซ้ำ ซึ่งเป็น 4 อย่างที่งาน Data Science ใช้ทุกวัน

ทบทวนหน้านี้ครบแล้ว จะทำได้

  • ใช้ตัวแปรและตัวดำเนินการคำนวณตัวเลขจากข้อมูลจริงได้
  • ใช้ if / else ให้โปรแกรมตัดสินใจตามเงื่อนไขได้
  • ใช้ for วนรวมข้อมูลทั้งลิสต์ได้
  • สร้างฟังก์ชันด้วย def ที่รับข้อมูลเข้าไปแล้ว return ผลลัพธ์ออกมาได้
  • ใช้ Gen AI ช่วยเขียนโค้ด แล้วตรวจเองได้ว่าโค้ดถูกจริง

ทำไมต้องทบทวน: Pandas, NumPy, Matplotlib และ Machine Learning ที่จะเรียนต่อจากนี้ สร้างจาก 4 เรื่องนี้ทั้งหมด ถ้าพื้นฐานแน่น บทต่อ ๆ ไปจะไม่สะดุด

ใช้ AI ในงานนี้: AI Work, Human Verify

ให้ AI ช่วยเขียนได้ แต่คนส่งงานคือเรา ต้องตรวจและรับผิดชอบทุกบรรทัด

AI Work

  1. บอกโจทย์ ข้อมูล และผลที่ต้องได้ให้ชัด
  2. สั่งให้แก้เฉพาะ TODO ห้ามแก้บรรทัด assert
  3. ขอให้อธิบายทีละบรรทัดด้วยภาษาง่าย ๆ

Human Verify

  1. รันผ่าน เห็น ✅ โดยไม่แตะ assert
  2. อธิบายได้ ทุกบรรทัดด้วยคำพูดตัวเอง
  3. ทดสอบได้ ทำภารกิจในกรอบเส้นประ และทายผลก่อนรัน
ข้อไหนใช้ AI ให้เขียน AI Log ใต้ข้อนั้นใน Text cell ว่าถาม AI ว่าอะไร และตรวจด้วยวิธีไหน

Quest 02 การเลือกทำ if - else

ถึงเป้าไหม

ร้านตั้งเป้าว่าต้องมีรายได้อย่างน้อย 500 บาทต่อวัน ให้เช็คว่าวันนี้ถึงเป้าหรือยัง

sales = 650
target = 500

# TODO: ถ้ายอดขายถึงเป้า ให้ message = "ยอดขายถึงเป้าหมาย"
#       ถ้าไม่ถึง ให้ message = "ยอดขายยังไม่ถึงเป้าหมาย"
message = ""

print(message)
assert message == "ยอดขายถึงเป้าหมาย"
print("✅ Quest 02 ผ่าน")
คำใบ้
โจทย์บอกว่า "อย่างน้อย" 500 แปลว่า 500 พอดีก็ถือว่าถึงเป้า ลองคิดว่าควรใช้ > หรือ >=
Human Verify: เปลี่ยน sales = 500 แล้วทายก่อนรันว่าจะขึ้นข้อความไหน ถ้าผลไม่ตรงกับความหมายของคำว่า "อย่างน้อย" แปลว่าเงื่อนไขยังผิด แม้ assert ตอน 650 จะผ่านก็ตาม

คำใบ้
